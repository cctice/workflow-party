# kfc-worker-acceptance-feedback-resolution

整理验收反馈处理结论和回流路径的 KFC skill。

## 适用场景

- 已收到人工验收、联调回归或复审反馈。
- 需要把反馈项整理成可执行的处理结论。
- 需要判断反馈处理后应回流到哪个阶段或步骤。

## 输入材料

- 验收反馈、问题描述或复审意见。
- 已有需求、设计、任务、验证或交付材料。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明反馈分类、处理建议、回流路径、未决项和后续动作。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-acceptance-feedback-resolution`
