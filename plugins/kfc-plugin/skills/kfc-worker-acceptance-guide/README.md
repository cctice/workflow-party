# kfc-worker-acceptance-guide

生成验收指南的 KFC skill。

## 适用场景

- 需求、设计、任务或验证材料已经形成，需要准备人工验收。
- 用户需要一份可直接用于验收的检查清单和验收说明。
- 当前阶段需要明确验收范围、验收路径和关注风险。

## 输入材料

- 需求、设计、任务拆分、实现记录或验证记录。
- 用户补充的验收口径、范围或业务约束。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明验收范围、验收步骤、检查点、预期结果、风险提示和人工确认项。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-acceptance-guide`
