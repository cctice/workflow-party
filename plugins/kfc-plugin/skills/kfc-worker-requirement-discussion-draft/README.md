# kfc-worker-requirement-discussion-draft

根据需求材料生成需求讨论稿的 KFC skill。

## 适用场景

- 需求还不够收敛，需要先整理成可讨论版本。
- 用户提供了零散想法、链接、文件、issue、聊天记录或会议纪要。
- 当前工作流需要识别已知信息、关键问题和下一步确认项。

## 输入材料

- 用户原始需求、上下文材料和补充说明。
- 已有产物、相关链接或当前工作流状态。
- 需要讨论的范围、目标或约束。

## 输出产物

产物应说明需求背景、已知信息、初步范围、关键问题、待确认项和建议讨论顺序。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-requirement-discussion-draft`
