# kfc-worker-solution-outline

根据需求基线生成概要设计的 KFC skill。

## 适用场景

- 需求已经形成基线，需要转成技术方案或业务实现方案。
- 用户需要明确系统边界、模块职责、关键流程和主要风险。
- 当前工作流需要形成详细设计前的方案轮廓。

## 输入材料

- 需求文档、需求讨论结论、业务规则和范围边界。
- 现有系统、接口、数据、依赖或约束信息。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明目标、范围、总体方案、模块拆分、关键流程、接口与数据影响、风险和待确认项。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-solution-outline`
