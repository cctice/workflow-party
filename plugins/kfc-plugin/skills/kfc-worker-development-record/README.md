# kfc-worker-development-record

记录开发执行结果、改动范围、验证入口和剩余风险的 KFC skill。

## 适用场景

- 当前阶段已经进入开发执行，且需要记录本轮开发结果。
- 编码工作已经完成或正在推进，需要整理给测试、自测、复核或验收使用。
- 用户希望 `/kfc 继续` 在开发阶段也能形成清晰的流程记录。

## 输入材料

- 任务包、详细设计、开发记录或实际代码改动。
- 修改文件、验证命令、运行结果、未验证原因或剩余风险。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明任务引用、实现摘要、改动范围、验证入口、未验证项、剩余风险和建议下一步。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-development-record`
