# kfc-worker-runtime-selftest-recorder

整理真实运行自测记录的 KFC skill。

## 适用场景

- 功能已经可以运行，需要记录真实运行路径和观察结果。
- 用户提供了运行入口、测试账号、操作步骤、截图、日志或现象。
- 当前工作流需要把自测证据整理给后续复核或验收使用。

## 输入材料

- 运行入口、环境、测试数据、账号权限和操作步骤。
- 实际运行结果、截图、日志、异常信息或未覆盖说明。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明自测范围、运行环境、操作步骤、实际结果、问题记录、未覆盖项和建议下一步。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-runtime-selftest-recorder`
