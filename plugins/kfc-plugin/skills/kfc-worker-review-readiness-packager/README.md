# kfc-worker-review-readiness-packager

整理人工复核准备材料的 KFC skill。

## 适用场景

- 自动化验证、运行自测或开发记录已经形成。
- 需要把复核材料整理给人工审查、代码审查、验收或发布前确认。
- 当前工作流需要说明可复核范围、证据、风险和未验证项。

## 输入材料

- 验证记录、自测记录、开发记录、代码审查结果或交付材料。
- 失败项、未验证项、外部依赖和剩余风险。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明复核范围、材料索引、验证摘要、风险清单、人工确认项和建议复核顺序。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-review-readiness-packager`
