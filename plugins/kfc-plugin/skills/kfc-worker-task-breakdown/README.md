# kfc-worker-task-breakdown

根据详细设计生成任务拆分和任务包的 KFC skill。

## 适用场景

- 详细设计已经形成，需要拆成可执行任务。
- 用户需要明确任务顺序、交付边界、依赖关系和验证入口。
- 当前工作流需要把设计材料转换为开发执行可消费的任务包。

## 输入材料

- 详细设计、方案说明、需求基线和相关约束。
- 代码结构、模块边界、接口与数据影响。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明任务总纲、任务列表、依赖关系、交付物、验证建议、风险和未决项。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-task-breakdown`
