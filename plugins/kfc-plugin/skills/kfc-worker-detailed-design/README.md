# kfc-worker-detailed-design

根据概要设计生成实现级详细设计的 KFC skill。

## 适用场景

- 已有需求基线和概要设计。
- 需要把方案细化到模块、接口、数据、状态、异常和验证路径。
- 当前工作流需要形成可供任务拆分和开发执行消费的设计材料。

## 输入材料

- 需求基线、概要设计、约束说明和已确认方案。
- 相关代码结构、接口约定、数据模型或外部依赖。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明实现结构、关键流程、接口与数据约定、边界条件、风险和验证建议。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-detailed-design`
