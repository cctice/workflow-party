# kfc-worker-lightweight-prd

根据已收敛需求材料生成轻量 PRD 的 KFC skill。

## 适用场景

- 需求已经基本明确，需要整理成开发、测试和评审可消费的文档。
- 用户提供了讨论稿、会议纪要、口头需求或已有材料。
- 当前工作流需要形成需求阶段的结构化产物。

## 输入材料

- 用户需求、业务背景、目标、范围和约束。
- 已有讨论稿、链接、文件、issue 或补充说明。
- 当前 KFC 阶段和工作流上下文。

## 输出产物

产物应说明背景目标、范围边界、用户故事或业务规则、功能要求、非功能要求、验收标准和未决项。用户可见输出必须包含：

- 产物路径
- 产物作用
- `produced_by: kfc-worker-lightweight-prd`
